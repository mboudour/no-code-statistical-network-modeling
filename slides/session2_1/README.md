# Session 2.1 Beamer deck

- `session2_1.tex` is the complete source for **Session 2.1: Temporal ERGMs for Network Change**.
- It contains **44 authored Beamer frames**, plus the supplied opening, agenda, and closing template assets. Therefore it exceeds the required 35 non-template frames.
- The companion app link on the fourth slide is the public **Streamlit app hosted on Render**: <https://no-code-statistical-network-modeling.onrender.com/>.
- The deck defines the discrete-time TERGM, support, risk sets, transition counts, first-order temporal effects, estimation distinctions, and simulation-based audits. It does not present the app's lag-only conditional-logistic computation as a general TERGM or STERGM.
- Compile with `pdflatex -interaction=nonstopmode -halt-on-error session2_1.tex` twice.
