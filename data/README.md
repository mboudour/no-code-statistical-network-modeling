# Public network data

The committed CSV files under `data/public/` are app-ready copies of **publicly documented** datasets. They are generated by session-specific scripts; do not edit topology, actor presence, or risk-set status manually.

## Session 1.1 — static binary ERGMs

| Files | Public source | Exact analytic scope |
|---|---|---|
| `florentine_business_*` | Statnet `ergm::flobusiness` | Undirected binary business-tie encoding for 16 Florentine families; verify 15 edges. |
| `sampson_liking_wave3_*` | Statnet `ergm::samplk3` | Directed binary liking nominations for the third survey wave; verify 18 vertices and 56 ties. |
| `lazega_advice_*` | Oxford RSiena `LazegaLawyers.zip` | Directed binary advice relation for 71 lawyers; the arc records the respondent's named adviser. |
| `davis_affiliation_*` | Davis, Gardner, and Gardner (1941), as distributed in NetworkX/Statnet | Undirected woman–event binary incidence graph; within-mode cells are structural zeros. |
| `kapferer_sociational_*` | Statnet `ergm::kapferer` | Undirected binary first-period sociational relation for a selected 39-worker panel. |

## Session 2.1 — repeated binary networks and risk sets

The Session 2.1 files are rebuilt by `scripts/build_session2_1_public_data.py`. The first-order lag-only TERGM app uses a **joint at-risk set** for every adjacent observed-wave pair. `transition_block` marks a documented observation break; it prevents a false one-step transition across a missing panel.

| Files | Public source | Exact response and support treatment |
|---|---|---|
| `knecht_friendship_temporal_*` | RSiena tutorial archive, `klas12b` | Four directed good-friend nomination panels. Codes for missingness, structural nonmembership, and the documented departure are excluded from the dyadic risk set. |
| `sampson_liking_temporal_*` | Statnet `ergm::samplk1`–`samplk3` | Three directed positive-affect/liking nomination panels for the same 18 labelled actors; relation panels are never pooled. |
| `coleman_friendship_temporal_*` | CRAN `sna::coleman` | Two directed Fall 1957/Spring 1958 nomination panels on a common 73-position roster; absent wave-specific presence information, the fixed-risk-set assumption is explicit. |
| `cow_alliances_1960_1970_temporal_*` | COW Formal Alliances v4.1 and State System Membership | Eleven annual undirected binary panels. A tie means at least one active formal alliance for a contemporaneous unordered COW-state pair; nonmember dyads are structurally unavailable. |
| `windsurfers_interaction_temporal_*` | Statnet `networkDynamic` beach panels | Repeated undirected binary daily observed-interaction panels. Actor absence is not a non-tie; the missing date 921 creates a `transition_block` break, so no 920-to-922 transition is fitted. |

## Restrictions that are part of the data design

- Session 1.1 fits **binary static** ERGMs only; it preserves directionality and bipartite support.
- Session 2.1 fits a **first-order lag-only discrete-time TERGM subclass**. Its displayed conditional logistic likelihood is exact only because all fitted statistics are functions of the preceding network; it is not a general contemporaneous-dependence TERGM or a STERGM.
- The Newcomb fraternity data are public, but are complete ordinal rankings with a fixed choice structure. They are documented in `session2_1_dataset_catalog.json` as an excluded candidate rather than forced into an unrestricted binary TERGM.
- Every source-specific caveat remains in the relevant data catalog and app workflow.
